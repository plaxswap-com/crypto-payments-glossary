# Crypto payments glossary for merchants

A one-page glossary of 35 terms a business meets when it starts taking crypto payments: confirmations, network fees, hosted checkout, payment links, webhooks, partial payments, overpayments, stablecoins, TRC-20, ERC-20, custody and more.

The page is plain HTML in `index.html`. It is published with Read the Docs.

Written by the [Plaxswap](https://plaxswap.com) team. Corrections are welcome as issues or pull requests.
